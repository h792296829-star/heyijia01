# 智能审核SaaS（纯后端示例）- FastAPI + SQLite

这个后端提供：
- 场景管理（scenes）
- 场景节点/规则（nodes）
- 触发记录/审核运行（runs）
- 审核执行：按场景节点顺序逐个调用 LLM（默认走 DashScope 的 OpenAI 兼容 Chat 接口）并合并结果

## 1) 运行（Docker，推荐）
1. 安装 Docker Desktop
2. 设置环境变量：`DASHSCOPE_API_KEY`
3. 启动：
```bash
docker compose up --build
```
4. 打开接口文档：`http://localhost:8000/docs`

## 2) 本地运行（非 Docker）
```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
export DASHSCOPE_API_KEY="sk-xxx"
uvicorn app.main:app --reload --port 8000
```

## 3) 接口简述
- `GET /api/scenes`
- `POST /api/scenes`
- `GET /api/scenes/{scene_id}`
- `PUT /api/scenes/{scene_id}`
- `GET /api/scenes/{scene_id}/nodes`
- `PUT /api/scenes/{scene_id}/nodes`  (整套节点覆盖保存，用于拖拽后保存坐标/顺序)
- `POST /api/runs`  (触发一次审核：传 scene_id + text)
- `GET /api/runs`
- `GET /api/runs/{run_id}`

> 前端联动：你现在的 HTML 可以把 “保存节点” 改成 `PUT /api/scenes/{id}/nodes`，
把 “触发记录详情” 改成 `GET /api/runs/{run_id}`，即可切成真实后台。

## 4) LLM 说明
默认使用 DashScope “OpenAI 兼容”接口（base_url 见阿里云文档）。
你也可以改为：OpenAI、火山、Claude 兼容端点等，只要实现 `LLMClient.chat()`。
